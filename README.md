# Stellar Horizons

 Stellar Horizons is a customization and performance enhancement mod by Liveplayer19, designed to make exploration more convenient while giving players greater control over visuals and rendering performance.

 ## Features

 **Infinite Fuel**\
 Enable infinite fuel for uninterrupted exploration without worrying about running out.

 **Infinite Oxygen**\
 Keep oxygen supplies unlimited, allowing you to explore for as long as you want.

 **Customizable Cloud Density**\
 Adjust cloud density to improve visual quality or reduce performance impact.

 **Extreme Render Distances**\
 Supports very high render distances while keeping the performance cost low, allowing you to see farther into the world.

 ## Configuration

 Stellar Horizons provides customizable options so you can configure the experience to match your preferences and hardware.

 | Feature | Description |
| --- | --- |
| Infinite Fuel | Removes fuel limitations |
| Infinite Oxygen | Removes oxygen limitations |
| Cloud Density | Customize the amount of clouds |
| Render Distance | Use extreme render distances |

## Installation

 1. Download the latest release of Stellar Horizons.
2. Install it using your preferred mod loader or mod installation method.
3. Launch the game.
4. Configure the available Stellar Horizons settings to your preference.

 ## Performance

 Stellar Horizons is designed with performance in mind. Cloud density can be reduced to improve performance, while the mod's render-distance optimizations allow for extended visibility without an unnecessarily large performance cost.

 Actual performance will vary depending on your hardware and other installed mods.

 Compatibility with specific game versions, mod loaders, or other mods depends on the implementation and should be verified for the release you're using.

 ## Disclaimer

 Features such as infinite fuel and oxygen can significantly change the intended gameplay experience. Use them according to your preferences.
